# Movie Ticket Booking System

## 1. Overview

A menu-driven C++ application for booking movie tickets in a single cinema. Users can view movies and shows, select seats, make payments, receive tickets, and cancel bookings.

## 2. Features

* View currently playing movies and their shows.
* Display seat availability for each show.
* Book one or more available seats.
* Calculate prices based on seat type:

  * Silver — Rs. 150
  * Gold — Rs. 250
  * Platinum — Rs. 400
* Support UPI, Cash, and Card payments.
* Generate tickets with booking and payment details.
* Cancel bookings and release the booked seats.

## 3. Design

The system was designed using:

* Requirement analysis
* Noun-verb analysis
* Class and relationship analysis
* UML class diagram
* Sequence diagram for booking and payment

## 4. Implementation

The project is implemented as modular C++ code using object-oriented design. Classes and methods are organized according to their responsibilities.

## 5. Code Quality

The implementation follows clean-code practices such as:

* Meaningful names
* Single-responsibility functions
* Named constants
* Minimal code duplication
* Short and focused methods
* Limited nesting

## 6. SOLID Principles

The design was reviewed against the SOLID principles, with particular focus on maintaining separate responsibilities and keeping the system easy to extend.

Unnecessary complexity and over-engineering were deliberately avoided to keep the system simple and suitable for a single-cinema application.

## 7. Testing

The system was tested for seat booking, unavailable seats, price calculation, successful and failed payments, ticket generation, and booking cancellation.

## 8. Completion

The required analysis, UML diagrams, implementation, testing, and documentation have been completed.
